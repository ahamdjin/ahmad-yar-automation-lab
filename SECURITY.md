# Security Policy

## Public repository rules

Do not commit API keys, OAuth tokens, passwords, private keys, cookies, webhook secrets, real customer data, private service URLs, internal hostnames, client account identifiers, or n8n execution data copied from production.

Use fictional sample data and placeholder domains such as `example.com`.

## Reporting a vulnerability

Do not publish exploitable security details in a public issue.

If GitHub private vulnerability reporting is available for this repository, use it. Otherwise, contact the maintainer through https://www.ahmadyar.co/ and provide only the minimum information needed to establish a private reporting channel.

## Scope

Security reports should concern code or workflows stored in this repository. Third-party services, n8n itself, and downstream deployments are outside this repository's security scope.
